# v1.2.0 — 随行料车连接与料车取料

本版改**车与料车的机械连接和取料来源**，不改旁白、字幕、时间轴（87.67s），
不改组件纵向铺装与阵列几何，也不改落板目标。

> 开源范围不变：代码/脚本/文档 **MIT**；示例视频与媒体 **All Rights Reserved**，
> 不允许二次创作、再分发或商用。详见 `LICENSE-DEMO.md`。

## 变更

- **车尾牵引（核心）**：机器人删除后部料架，改为后横梁 + 牵引杆 + 牵引盒 + 锁扣 + 销；
  料车加 A 形牵引架、牵引环/锁扣、安全链、收起的支撑腿与摇把。两牵引盒中心距 0.058m，
  盒体互相嵌入，牵引点世界 z≈12.9；机器人换位时料车作为子节点整体随动，连接不脱开。
- **料车承载组件**：可牵引平板车 2.7×3.2m、双轴四轮；中部 16 边旋转料台 + 木托盘，
  5 块组件（世界中心 `(3.8, 1.86+0.12i, 15.10)`）由 Godot 逐块生成，便于拾取/隐藏。
  托盘端板改为前后低横档，不再遮挡料堆。
- **从料车取料**：上料位姿改为在料车上方下降（yaw=180、d=5.1），先高位越过车尾控制柜；
  首次抓取 t=29.70、第二次 t=70.20（机器人换位到 z=8.75 后）。抓起升至 h≈4.6 再转运。
- **镜头**：上料段右后侧低角度先看到牵引杆/挂钩，再升到料台上方；转运与二次取料改为跟随
  吸盘；自动换位用右后侧视角；落板改为近景。HUD 新增“随行料车”标注（左侧，20.8s 起）。
- **重渲**：1920×1080、30fps、2630 帧、87.67s；H.264 High + AAC 48kHz；
  音频沿用 v1.1.0（峰值 −3.4 dBFS、均值 −18 dB）；无 ≥0.15s 黑段。

## 数值验证

- 抓取：t=29.70 `grip=(3.8, 2.341875, 15.09994)` err=0.002；
  t=70.20 `grip=(3.8, 2.223363, 13.84989)` err=0.003。
- 首次落板：`grip=(0.000047, 1.420832, 10.0)`，法线≈(0.342, 0.940, 0)，角高 1.831 / 1.011。
- 第二次落板：`grip=(0.000305, 1.431785, 8.75)`，角高 1.842 / 1.022。
- 穿模：两连杆按抓取/携行位姿采样，对车尾控制柜最小间距 0.66m。
- 组件堆世界中心：`(3.8, 1.86+0.12i, 15.10)`，i=0..4；第二块/顶块与抓取高度 2.22 / 2.34 对应。
