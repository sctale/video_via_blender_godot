# 萌兽峡谷 TapArena · 30 秒宣传片（体素演绎）

用本仓库管线制作的一支独立成片：Blender 程序化体素资产 → Godot 4 实时导演 + Movie Maker
逐帧渲染 → edge-tts 中文配音 → numpy 原创 BGM → ffmpeg 混音压制。
与丽天智能 MMR 示例片共用同一套方法，换主题、换角色、换分镜。

## 规格

- 1920×1080 / 30fps / 900 帧 / 30.0s / H.264 high（约 13 Mbps）/ AAC 48kHz 双声道
- 配音：`zh-CN-XiaoyiNeural`（晓伊，+3%），5 段旁白
- 音乐：numpy 合成 108 BPM 原创儿童冒险旋律（无外部曲库）
