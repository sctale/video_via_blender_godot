# v1.4.1 — 恢复经典镜头

用户确认 v1.3.1 的镜头语言更好、该展示的内容都展示了。本版因此**撤销 v1.4.0 的
21 镜头重排**，原样恢复经典 10 镜头；v1.4.0 的灯光、材质、机械细节、声音与 BT.709
验收全部保留。

## 变更

- `Main.gd`：从 v1.3.1 提交 `2505e7e` 恢复 `shots` 经典表，机位、运动、FOV、切镜点完全一致。
- 保留 v1.4.0 的黄金时刻光照、轻后期、机械液压/轮毂/履带细节、沙地法线与车辙、
  同步音效、分层 BGM 和两遍 loudnorm。
- 新增 `CAMERA_AUDIT=1`：对 grip / 当前组件 / 安装落点 / 车身输出屏幕坐标与
  AABB 遮挡检查，作为后续改镜头的验收工具。
- `preview_stills.ps1 -Audit`：一键输出关键静帧、contact sheet 与可见性审计日志。

## 验证结果

- 1920×1080 / 30fps / **2630 帧 / 87.667s**；H.264 High + AAC 48kHz 立体声。
- `pix_fmt=yuv420p`、`color_range=tv`、BT.709 matrix/transfer/primaries 三标记齐全。
- 综合响度 **-16.0 LUFS**，true peak **-2.0 dBTP**；无 ≥0.15s 黑段。
- 抓取 err ≤0.002m；落板角高与 v1.3.1 基本一致。
- 关键样帧复核：料车、机械臂、吸盘、组件与安装排均清晰可见。
- MP4 151,531,445 B（约 144.5 MiB）；`poster.jpg` 423,900 B；
  `contact_sheet.jpg` 693,446 B。
