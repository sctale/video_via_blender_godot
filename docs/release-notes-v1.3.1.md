# v1.3.1 — 设备标注引线连接修正

修一处 HUD 缺陷：设备标注的白线没有连到名称框（14s 附近“机械臂”最明显——名称框被
安全区 `clamp` 下移后，引线仍画向夹取前的坐标，线头悬在框上方）。本版只改标注引线，
模型、相机、动作、旁白、字幕、BGM 与时长（87.669s）均不变。

> 开源范围不变：代码/脚本/文档 **MIT**；示例视频与媒体 **All Rights Reserved**，
> 不允许二次创作、再分发或商用。详见 `LICENSE-DEMO.md`。

## 变更

- `HUD.gd::_draw_callouts()`：先夹取名称框，再取“锚点→框中心”线段与框矩形的交点
  （slab 法）作为引线终点；框被夹到画面安全区时引线仍接在边框上，退化时回退框中心。
- 标注的出现时间与偏移（`CALL_OUTS`）不变。

## 验证

- t=14.0 静帧：“机械臂”白线接到框左边框，框上方的悬空段消失。
- t=21.5 静帧：“机械臂 / 3D 视觉 / 真空吸盘 / 随行料车”四条引线全部接框。
- 成片：1920×1080 / 30fps / 2630 帧 / 87.669s；H.264 High + AAC 48kHz 立体声；
  峰值 −3.4 dBFS、均值 −18.0 dB；无 ≥0.15s 黑段。
