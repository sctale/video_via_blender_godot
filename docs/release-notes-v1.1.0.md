# v1.1.0 — 吸盘中心连接与实机外观精修

本版只改**外观与机械连接**，不改旁白、字幕、时间轴，也不改组件纵向铺装与阵列几何。

## 变更

- **吸盘架中心连接（核心）**：腕部 `Wrist` 由 4.8m 移至吸盘架几何中心 5.8m；上臂连杆
  2.3 → 3.3m；`EffectorYaw` / `Effector` 同在 5.8；`Grip` 仅在腕部正下方 −0.58m。
  Godot：`L2=3.3`、`GRIP_FWD=0.0`、`GRIP_DOWN=0.58`。机械臂末端始终接在吸盘架中心，
  不再接在后缘。
- **薄型吸盘架 + 6 吸盘**：2.8m 双梁 + 侧梁 + 中心安装板 + 顶部盖板；
  6 只蓝色吸盘（3 列 × 2 排，x=−0.9/0/+0.9，y=±0.35）。
- **圆润布套基座**：底部 1.12 → 鼓腹 1.36 → 1.08 → 顶部 0.82 的四层团块，
  保留褶皱环与黑色管线。
- **圆筒旋转料仓拖车**：16 边圆筒（半径 1.25、倾角 25°）+ 4 块组件 + 木托盘 +
  绿色绑带 + 4 个黄色轮毂/黑色轮胎 + 灰色车架 + 牵引杆；作为陈设停在机器人左后侧，
  不参与取料动作。
- **重渲**：1920×1080、30fps、2630 帧、87.67s；H.264 High + AAC 48kHz；
  音频与 v1.0.0 相同（峰值 −3.4 dBFS、均值 −18 dB）。

## 数值验证

- 抓取：grip=(3.8, 2.735083, 11.79955)，attach err=0.005。
- 首次落板：grip=(0, 1.42, 10.00)，法线 (0.342, 0.940, 0)，组件两角高 1.830 / 1.010。
- 第二次落板：grip=(0, 1.43, 8.75)，组件两角高 1.840 / 1.020。
- 腕部到 grip 仅 0.58m 垂直偏移，无前伸偏置。
