# v1.2.1 — 控制柜承托修正与平板料车

本版只修 v1.2.0 的两处目视问题：后部控制柜悬空、料车仍是圆台式形态。
旁白、字幕、BGM、时间轴（87.67s）、抓取/落板动作与镜头均不变。

> 不允许二次创作、再分发或商用。详见 `LICENSE-DEMO.md`。

## 变更

- **控制柜落地（核心）**：车尾新增与主车身同宽的后部设备舱（白色车体 + 绿色裙边 +
  银灰顶板 + 深色腰线），y −3.135…−1.985，正好托住控制柜投影
  y −3.125…−2.375。柜底与顶板嵌入 0.015m，侧视/后视不再悬空；尾部两侧补品牌标识。
- **平板料车**：删除 16 边旋转圆台（`TurnBase/TurnRing/Turntable/TurnRim`），改为
  白色车斗 2.7×3.2×0.62：绿色上下饰带、银灰台面、四角白立柱、侧面车身缝；
  黑胎 + 银灰轮毂 + 白色挡泥板；木托盘与组件垛位置不变，直接坐在车斗台面上。
- **HUD**：“随行料车”标注锚点由 `Turntable` 改为 `TrailerBody`。
- **重渲**：1920×1080、30fps、2630 帧、87.669s；H.264 High + AAC 48kHz；
  音频沿用（峰值 −3.4 dBFS、均值 −18 dB）；无 ≥0.15s 黑段。

## 数值验证

- 抓取：t=29.70 `grip=(3.8, 2.341875, 15.09994)` err=0.002；
  t=70.20 `grip=(3.8, 2.223363, 13.84989)` err=0.003。
- 落板：t=57.00 角高 1.831 / 1.011；t=74.90 角高 1.842 / 1.022。
- 料车 GLB 节点校验：无 `Turn*`，含 `TrailerBody`；托盘底仍为 1.74，
  组件世界中心仍为 `(3.8, 1.86+0.12i, 15.10)`。
- 牵引盒中心距仍约 0.058m，牵引杆/锁扣/支撑腿几何未动。
