# v1.3.0 — 随行料车换到另一端 · 倾斜料鼓与循环安装

本版按用户实机图重做料车与挂接：控制柜在一端，随行料车挂在**另一端**；
料车恢复为**倾斜 25° 的 16 边料鼓 + 木托盘 + 5 块组件垛**（绿色绑带、四轮黄毂、
A 形牵引架），不再使用白色平板车斗。旁白、字幕、BGM、时间轴（87.669s）与
两次抓取/落板事件时刻不变。

> 不允许二次创作、再分发或商用。详见 `LICENSE-DEMO.md`。

## 变更

- **料车换到 −z 端（核心）**：料车节点移到机器人前方 `(0, 0, −5.582)` 并旋转 180°，
  牵引架朝向车体；机器人挂钩由尾部改到前端 `FrontHitch*`，控制柜与后舱承托留在 +z 端。
  画面中控制柜与料鼓分处车体两端，与实机图一致。
- **倾斜料鼓**：16 边圆鼓半径 1.25 m、厚 0.5 m，轴线朝上并向车体倾斜 25°；
  深色鼓缘、中心毂、4 个手孔（±0.75, ±0.85）；鼓下支撑座。
- **托盘与组件垛**：倾斜木托盘 + 5 块组件沿鼓面法线排列（间距 0.13），
  两侧各两道 0.03 m 薄绿色绑带；垛顶世界高度 2.544 m。
- **四轮底盘**：2.3×1.5 平板 + 2.4×1.6 车架，双轴四轮外露（x=±1.32、y=±0.7），
  黑胎 + 黄色轮毂；删除遮挡车轮的大 `ChassisBox`。A 形牵引架 + 锁扣 + 支撑腿/摇把 + 安全链。
- **取料**：吸盘按鼓面 25° 取板，提起后转平再转运；顶部两块（i=4/i=3）依次取走。
- **镜头**：片头/环绕改为同时看到“控制柜端—车体—料鼓端”的侧前方机位；
  上料低角度看鼓面并升至垛顶；转运/对位/落板与二次取料重新构图；
  二次落板近景在 77.2s 切结尾环绕，避免吸盘归位时扫过镜头。
- **HUD**：“随行料车”标注锚点改为 `Drum`，与“真空吸盘”标注错开。

## 数值验证

- 挂接：`FrontCoupler` 世界 `(3.8, 0.55, 7.05)`，料车 `Coupler` `(3.8, 0.58, 7.05)`，
  中心距 **0.030 m**；机器人换位后料车随动。
- 抓取：t=29.70 `grip=(3.8, 2.544, 4.9)` err=0.001；
  t=70.20 `grip=(3.8, 2.426, 3.595)` err=0.001。
- 落板：t=57.00 角高 1.8304 / 1.0096；t=74.90 角高 1.8404 / 1.0196。
- 料车 GLB 35 节点：含 `Drum/DrumRim/DrumBase/DrumMount/PalletBase/Strap_*/Tire_*/Hub_*/Tongue_*`，
  无 `TrailerBody/Turn*/ChassisBox`；机器人 GLB 无 `RearHitch*/RearCoupler*`。
