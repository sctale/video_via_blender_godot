# SPEC v1.2.0 — 随行料车连接 + 从料车取料

> 基于已发布的 v1.1.0 成片。视频与媒体仍为 **All Rights Reserved**（不允许二次创作/再分发）；
> 仅制作方法（代码/文档）MIT。官方参考照片不进入开源仓库。

## 背景 / 目标

v1.1.0 中圆形料仓拖车只是远处陈设：与机器人之间没有物理连接；机械臂抓取仍从机器人车身的
后部料架完成。用户指出三点：**料车没有和机器人车连在一起**、**取料应该从料车取**、
**机器人车体不应该有料架**。

本版把料车改成可牵引的随行料车：车尾有牵引杆/挂钩与料车牵引环对接；删除机器人车身料架；
5 块组件放到料车的旋转料台上；机械臂从料车抓取、转运、落板。重渲并发布 v1.2.0。

## 范围（本次不做）

- 不改旁白、字幕、BGM、时间轴时长（87.68s）；旁白中的“承载平台”即料车工作台。
- 不改阵列/导轨/纵向铺装几何；落板目标（x=0，z=10.00/8.75，20° 法线）保持不变。
- 不做车轮滚动动画；机器人换位时料车作为子节点整体随动，牵引连接保持。
- 不修改 v1.0.0 / v1.1.0 Release；不加 GitHub Actions。

## 改动清单

### A. 机器人：删除料架 + 后部牵引

- 删除原后部料架：`LoadPlatform`、`LoadPallet`、`LoadGuide_L/R`、`LoadGate`、`LoadGateTrim`。
- 新增后牵引：`RearHitchMount`（底盘后横梁）、`RearDrawbar`（0.18×1.15×0.14，z≈0.55）、
  `RearCoupler`（0.34×0.26×0.20）与牵引销；牵引头位于机器人本地 z≈+3.05（Blender y≈−3.05）。
- 后控制柜、履带、车身、前部设备箱、品牌标识保持不动；牵引杆从控制柜下方伸出。

### B. 料车：可牵引的旋转料台

- 平板车体 2.7×3.2m：车架/甲板/绿色侧栏；双轴 4 轮（黑胎 + 黄毂 + 绿挡泥板）。
- 前部 A 形牵引架（两根斜梁 + 横梁 + 牵引环 + 锁扣 + 安全链 + 收起的支撑腿），
  牵引环位于料车本地 y=3.0（Godot z=−3.0），与机器人牵引头在 z≈12.9 世界处搭接。
- 中部 16 边旋转料台（半径 1.3m）+ 木托盘 + 托盘端板；料台中心 y=0.8（Godot z=−0.8）。
- **组件不进 GLB**，由 Godot 在料车上生成 5 块可拾取组件（本地 x=0，z=−0.8，y=1.86+0.12i）；
  顶块中心 y=2.34，第二块 y=2.22；组件保持与机身料架相同的水平拾取姿态。

### C. Godot：连接、抓取、镜头

- 料车实例作为 `robot` 子节点，local `(0, 0, 5.9)`，rotY=0；机器人 z 换位时料车同步平移。
- `stack_panels` 由底盘改为料车料台；抓取目标改为 `(ROBOT_X, 2.34/2.22, robot.z + 5.1)`。
- 抓取位姿：yaw=180、d≈5.1；先高位接近（h≈4.3）越过车尾控制柜，再在料车上方下降到
  h=2.34/2.22；抓起后升到 h≈4.6，再 yaw 120→90 转运；落板段位姿不变。
- 事件：首次抓取 t=29.7 index=4；第二次 t=70.2 index=3；第二次前机器人已换位到 z=8.75，
  料车随动，抓取 d 仍为 5.1。
- 镜头：
  - 上料段改为右后侧机位，先低角度看到牵引杆/挂钩，再升到料台上方看吸盘下降；
  - 转运转运段跟随 `grip`；换位段用右后侧视角看第二次从料车抓取；
  - 片头环绕与片尾拉远重新构图，确保料车与机器人同框且不挡住主体；
  - HUD 增加“随行料车”标注（约 t=20.8–22.6）。
- 旁白/字幕/时间轴/BGM 不变，音频直接沿用 v1.1.0 的 `audio/mix.m4a`。

### D. 重渲与发布

- 重建 Blender GLB/贴图 → Godot 导入 → 关键帧静帧复核 → 1080p30 终渲。

## 验收

1. **连接**：机器人 GLB 不再含 `Load*` 节点；`RearCoupler` 与料车 `Coupler` 的世界距离
   ≤0.05m（z≈12.9）；机器人换位前后牵引点相对位移一致，无断开。
2. **取料**：首次抓取 `grip` 与料车顶块中心 `(3.8, 2.34, 15.10)` 距离 ≤0.02；
   第二次 `(3.8, 2.22, 13.85)` 距离 ≤0.02；抓取后料车对应组件隐藏；
   机械臂在车尾控制柜（z∈[11.86,13.13]，高 2.04–3.16）上方通过，无穿模、无遮挡穿帮。
3. **落板**：仍为 `grip=(0,1.42,10.00)` 与 `(0,1.43,8.75)`，法线 20°，角高约 1.83/1.01、
   1.84/1.02。
4. **成片**：1920×1080、30fps、≈87.7s、H.264 + AAC 48k；无黑帧；音频沿用 v1.1.0
   （峰值 ≤ −1 dBFS）；画面能看到“机器人—牵引杆—料车—料台”的完整连接关系。
5. **仓库**：代码 MIT / 媒体 ARR 声明不变；Release v1.2.0 含 mp4/poster/contact sheet；
   README 版本与 Release 对应；官方参考照片不进入仓库。
