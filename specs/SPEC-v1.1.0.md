# SPEC v1.1.0 — MMR 外观精修与吸盘中心连接

> 基于 v1.0.0 成片（已发布）与用户提供的 LEAPTING 官方 MMR 侧视参考图。

## 背景 / 目标

v1.0.0 已完成并发布。用户指出：**机械臂与吸盘架的连接应始终在吸盘架中心**（当前连接点
在架后缘，且有 1.0m 的前伸工具偏置，视觉上不在中心）；同时希望按官方图进一步精修外形：
圆形旋转料仓拖车、薄型斜角吸盘架 + 细长杆蓝吸盘、圆润的橙色布套臂基座。完成后重渲并发布
video **v1.1.0**。

## 范围（本次不做）

- 不把取料动作改成“从拖车料仓取料”；仍从机身料架取料，拖车为陈设。
- 不改旁白、字幕、时间轴、BGM；不改纵向铺装与阵列几何。
- 不修改 v1.0.0 Release；新增 v1.1.0。
- 不把官方参考照片复制进开源仓库；仅用于对照。

## 改动清单

### A. 吸盘中心连接（核心）

- Blender：
  - `Wrist` 由 y=4.8 移至 **y=5.8（吸盘架中心）**；上臂连杆 2.3 → **3.3**
    （肘 y=2.5 → 腕 y=5.8）；腕关节、法兰、相机以腕轴为中心对称。
  - `EffectorYaw` / `Effector` 同在 y=5.8；`Grip` 在腕部正下方 −0.58；
    **取消 1.0m 前伸偏置**；吸盘架横梁/侧梁/铰链/中心安装板以腕轴为几何中心。
  - 机械臂末端从“接在架子后缘”变为“接在架子正中”，与实机一致。
- Godot：
  - `L2 = 3.3`；`GRIP_FWD = 0.0`；`GRIP_DOWN = 0.58`；其余世界空间位姿目标不变。
  - 验证抓取/落板/第二次落板时 `grip` 与吸盘架中心重合，组件法线与角高保持。
- 预期影响：home/lift 姿态会变化（上臂变长、工具偏置消失）；必要时微调 `pose_keys`
  与镜头，保持构图不穿帮。

### B. 吸盘架

- 两根 2.8m 银色横梁（截面 0.12）+ 侧梁 + 中心安装板；顶部薄型斜角盖板/相机盒。
- **6 个吸盘**（3 列 × 2 排，x = −0.9 / 0 / +0.9；y = ±0.35），更小的蓝色吸盘（0.22）
  + 细长杆；保持绕组件法线旋转（`EffectorYaw`）。
- 吸盘底面与组件上表面接触（grip y=2.47，组件顶 2.515）；保持落板姿态与角高。

### C. 布套臂基座

- 阶梯“方塔”改为**圆润的橙色布套团块**：4 层由宽到窄、轻微错位/旋转，褶皱环与黑色管线保留；
  降低方盒感，关节枢轴不变。

### D. 圆形旋转料仓拖车（陈设）

- 替换现有小平板车：灰色圆筒/转盘（16 边）半径 1.25、倾角 25°，上置 4 块组件 +
  木托盘 + 绿色绑带；4 个黄色轮毂 + 黑色轮胎、灰色车架、牵引杆。
- 位置 `(-3.6, 0, 16.0)`，rotY=90（机器人左后侧，不参与动作、不挡主要镜头）。
- 组件使用面板材质（示例媒体，ARR）。

### E. 重渲与发布

- 重建 GLB/贴图 → Godot 导入 → 关键帧视觉复核 → 1080p30 终渲。
- 新产物：`installation-robot-v1.1.0.mp4`、`poster-v1.1.0.png`、`contact_sheet-v1.1.0.png`。
- 更新开源仓库：同步 Blender/Godot 代码与 SPEC；README 链接切 v1.1.0；
  新增 `docs/release-notes-v1.1.0.md`；创建 Release **v1.1.0**（成片/媒体 ARR，方法 MIT）。
  v1.0.0 Release 保留。

## 验收

1. **几何**：腕部关节与吸盘架中心重合；腕→grip 仅 0.58m 垂直偏移、无前伸；
   首次落板 grip=(0,1.42,10.00)、法线 20°、角高 1.01/1.83；第二次 (0,1.43,8.75)。
2. **视觉**：圆筒料仓拖车、薄架/6 蓝杯、圆润橙色基座成立；无穿模；镜头不穿帮；
   标题/字幕/HUD 正常。
3. **成片**：1920×1080、30fps、≈87.7s、H.264 + AAC 48k；无黑帧；音频峰值 ≤ −1 dBFS。
4. **仓库**：代码 MIT、媒体 ARR 声明不变；Release v1.1.0 含 mp4/poster/contact sheet；
   README 链接与 Release 对应。
5. 官方参考照片不进入仓库。
