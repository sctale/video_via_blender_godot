# SPEC v1.2.1 — 控制柜承托修正 + 平板料车形态

> 基于 v1.2.0 成片的两处目视问题修正。视频与媒体仍为 **All Rights Reserved**；
> 仅制作方法（代码/文档）MIT。旁白/字幕/BGM/时间轴不变（87.67s）。

## 背景 / 目标

v1.2.0 发布后用户指出：

1. **控制箱和主体分离**：后部白色控制柜位于 z=12.375–13.125，车体白车身只到
   z=12.0，柜体底部 2.025 以下没有任何车体承托，侧視可见悬空。
2. **圆筒拖车形态不对**：料车中部是一个 16 边灰色圆台 + 绿圈，读起来像“圆筒/蛋糕台”；
   实机随行料车是低平板白色料车（白色车斗、低侧板、黑胎银毂、木托盘 + 组件垛）。

本版只修这两处形态；抓取/落板数值、镜头、HUD 文案、声音与时长均沿用 v1.2.0。

## 范围（本次不做）

- 不动组件垛位置（世界中心 `(3.8, 1.86+0.12i, 15.10)`）与抓取高度 2.34/2.22。
- 不动牵引点位置（z≈12.9）与牵引杆/挂钩尺寸。
- 不动镜头关键帧、旁白、字幕、BGM、时间轴。
- 不修改 v1.0.0/v1.1.0/v1.2.0 Release；v1.2.0 保留。

## 改动清单

### A. 机器人：后部设备舱承托控制柜

- 在车体后方新增与主车身同宽的**后部设备舱**（y=−3.135…−1.985）：
  - `RearBody`：白色，宽 2.0 × 深 1.15 × 高 0.62（z 1.40–2.02）；
  - `RearSkirt`：绿色，同宽 × 高 0.45（z 0.935–1.385），并加侧通风口；
  - `RearDeckPlate`：银灰顶板 z≈2.015，控制柜底面 2.025 直接落座；
  - `RearBodyLowerTrim`：深色腰线；侧面加两道车身缝。
- 控制柜、柜门缝、散热孔、顶灯、品牌贴花全部保持原位；柜体不再有悬空段。
- 后牵引（横梁/牵引杆/牵引盒/锁扣/销）保持原位，位于后舱下方，仍可从低角度看到。

### B. 料车：白色平板料车（去掉圆筒料台）

- 删除 `TurnBase` / `TurnRing` / `Turntable` / `TurnRim` 四个圆台件。
- 车体改为白色车斗：宽 2.7 × 长 3.2，车斗顶面 z≈1.70，银灰台面 1.70–1.74；
  上下各一条绿色饰带，侧面车身缝；四角白色立柱（高出台面 0.5），黑胎 + 银灰轮毂 +
  白色挡泥板；保留双轴四轮、A 形牵引架、牵引环、锁扣、支撑腿/摇把、安全链。
- 木托盘与端板保持原位（托盘底 1.74，组件垛高度不变），直接坐在车斗台面上。
- 颜色与实机参考一致：白车斗、深色车架、银色台面；绿色只作饰带。

### C. Godot / HUD

- “随行料车”标注锚点由 `Turntable` 改为 `TrailerBody`（世界约 (3.8, 1.28, 15.5)）。
- 抓取/落板/事件/镜头代码不改；仅重编资产与重渲。

### D. 重渲与发布
