# SPEC v1.4.0 — 电影化质量升级

> 基线：v1.3.1（1920×1080 / 30fps / 2630 帧 / 87.669s）。
> 目标：保留体素原创风格与现有作业流程，把“技术演示”提升为“黄金时刻工业产品片”，
> 同时把预览、混音、验收做成可复跑流程。

## 审计结论

- 声音只有 TTS + pad/arp/wind，无机械/吸附/落板音效；人声第 6 段偏轻，侧链 attack 180ms 偏慢。
- 画面环境光 0.9、太阳 1.25、shadow_normal_bias 1.5，光照平、阴影浮；缺少层次与后期。
- 10 个镜头全部统一 smoothstep、固定 FOV，设备环绕 15.66s，关键吸附/释放缺近景。
- 履带/轮胎为静态方块，换位仅整车平移；AA 只有 2×MSAA。
- 终渲脚本只强制检查分辨率；MP4 实测为全范围 yuvj420p，未显式 BT.709。

## 目标与范围

**做：**

1. **电影化灯光/后期**：暖低角度太阳 + 冷辅光/轮廓光，降低环境光，修正阴影 bias；
   加轻 SSAO/辉光/雾、AgX 或 Filmic 曝光、暗角/细颗粒/轻暖调；4×MSAA + FXAA。
2. **镜头语言**：重排为约 18–21 个镜头，混合广角/35/50/85mm 等效 FOV；
   吸附、对位、释放增加近景，动作末段 ease-out，避免匀速“起步—停车”。
3. **机械细节**：关节轴/螺栓/液压杆/管线；料车低多边形轮毂与胎纹；履带板循环、
   轮毂旋转、换位轻微车身起伏与料车牵引摆动。
4. **材质/环境**：更高分辨率沙地纹理 + 法线、车辙；组件电池片/金属边框反光；
   保留现有光伏阵列/云/远山，不重做场景。
5. **声音设计**：新增与事件同步的伺服、液压、吸附、释放、落板、行驶、确认音；
   分层 BGM、逐段人声归一、20ms attack 侧链、两遍 loudnorm（-16 LUFS / TP -1.0）。
6. **流程/验收**：关键时间点静帧预览、自动黑段/规格/响度/色彩范围检查、
   event-based contact sheet；输出 BT.709 limited range。

**不做：**

- 不改作业事件时刻、IK 目标、旁白文案、字幕内容与总时长。
- 不引入外部商业素材；模型/贴图/音效继续程序化原创。
- 不重做整座光伏电站或更换品牌视觉。

## 验收标准

1. 同机位 A/B（14s / 29.7s / 47.6s / 57s / 66.5s / 75s）：曝光、阴影、材质层次、
   镜头构图有可见提升；无新增穿模、镜头入物体、HUD 被后期污染。
2. 抓取/落板数值不变：attach err ≤0.003m；落板角高差与 v1.3.1 一致。
3. 2630 帧 / 87.667s / 1920×1080 / 30fps；H.264 High + AAC 48kHz stereo。
4. 视频 `pix_fmt=yuv420p`、`color_range=tv`、BT.709 三标记；无 ≥0.15s 黑段。
5. 音频约 -16 LUFS，true peak ≤ -1.0 dBTP；旁白清晰，音乐/环境在人声下 duck 8–12dB；
   四个作业事件均有可辨认音效。
6. `verify_video.ps1` 全绿并输出 JSON 报告；Release 资产摘要与本地一致。

## 验证方法

- 先以 `STILL_T` 渲染 0.5/14/21.5/29.7/47.6/57/66.5/70.2/75/82s 静帧，逐张检查。
- 音频先单独试听/测响度，再进入全量渲染。
- 全量渲染后用 `verify_video.ps1` 做规格、黑段、EBU R128、色彩标记与抽帧检查。
