# SPEC v1.3.1 — 设备标注引线连接修正

> 用户反馈：14s 附近“机械臂”标注的白线没有连到名称框，线头停在框上方。
> 本版只修 HUD 引线，模型/镜头/动作/旁白/BGM/时长不变。

## 目标

设备标注的引线始终终止在名称框边框上；名称框被夹到画面安全区时也不脱线。

## 范围（不做）

- 不改相机、机器人/料车、事件时刻、字幕文案、音频。
- 不调整标注出现时间与偏移量（`CALL_OUTS` 的 `at/dx/dy` 保持不变）。
- 不覆盖已发布的 v1.3.0；另发 v1.3.1。

## 改动清单

- `godot/scripts/HUD.gd` `_draw_callouts()`：
  - 先按安全区夹取名称框 `box`，再取“锚点→框中心”线段与 `box` 的矩形交点（slab 法），
    引线画到该交点；退化时回退到框中心。
  - 原先引线画到夹取前的 `(lx, ly)`，框被 `clamp` 下移时线头悬空。

## 验收

1. t=14.0 静帧：“机械臂”白线接到框左边框，无可见间隙。
2. t=21.5 静帧：“机械臂/3D 视觉/真空吸盘/随行料车”四条引线全部接框。
3. 成片仍为 1920×1080 / 30fps / 2630 帧 / 87.669s；音频峰值/均值不变；无 ≥0.15s 黑段。
4. 产物 `installation-robot-v1.3.1.mp4`、`poster-v1.3.1.png`、`contact_sheet-v1.3.1.png`；
   Release v1.3.1 资产摘要与本地一致；v1.3.0 保留。
